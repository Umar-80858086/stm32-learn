\# STM32Cube IDE Workspace



This repository contains my STM32Cube IDE workspace, including hands-on embedded systems projects developed using STM32 microcontrollers. The projects focus on core embedded concepts such as peripheral configuration, UART communication, task scheduling, and low-level firmware development. This workspace reflects my practical learning, experimentation, and implementation of real-world embedded systems use cases using STM32CubeIDE and HAL/LL drivers.
